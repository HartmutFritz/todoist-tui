# Security policy

Please report security issues privately to the project maintainers rather than
opening a public issue. Include the affected version, reproduction steps, and
the potential impact. Maintainers should acknowledge a report promptly and
coordinate disclosure after a fix is available.

`todoist-tui` handles Todoist API tokens and private task data. Reports involving
credential exposure, unsafe logging, database corruption, command injection,
or unintended network transmission are especially important.

Never include a real `API_TOKEN` or an unredacted task database in a report.
